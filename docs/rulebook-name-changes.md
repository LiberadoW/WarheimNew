# Rulebook name changes

Applied after the owner’s PR #5 review on 13 October 2026. These are catalog names and names shown in the app. Old saved rosters are translated when opened; custom model names, campaign stats, equipment, experience, IDs and battle history are preserved. Hired-sword names are unaffected.

Recruitment restrictions such as “tylko …” and permitted magic colleges remain rules/options rather than part of a unit’s name. Army names remain in the nominative case, rather than copying inflected forms from sentences in the source.
